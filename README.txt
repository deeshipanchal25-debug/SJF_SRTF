RESEARCH-FOCUSED CPU SCHEDULING WEBSITE

Files:
- index.html: introduction, research-review findings, application and simulator
- css/style.css: responsive light-theme styling
- js/app.js: scheduling and comparison logic

How to run:
1. Extract the ZIP file.
2. Open index.html in Chrome, Edge or Firefox.
3. Scroll to Interactive Simulation.
4. Enter Arrival Time, Actual Burst Time and Estimated Burst Time for each process.
5. Select SJF or SRTF and click Run comparison.

Important academic note:
The estimated burst time is entered manually to demonstrate the research workflow. This prototype does not train or run a machine-learning model. The actual burst time determines when a process completes; estimated values affect scheduling decisions. The findings section is based on the research-review description in the project report. Verify the original publication and its numerical results before presenting paper-specific experimental claims.
